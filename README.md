## test.2.4 重點

- **這次一次性清除舊測試資料**：第一次啟動 2.4 會刪除先前 localStorage 測試資料；之後重新整理不會重複清除。
- 結算頁改成以「待我確認 / 我要付 / 我要收 / 已完成」為主。
- 付款人直接看到要付給誰、待確認多少、還剩多少。
- 收款人直接看到哪些人尚未付款與金額。
- 新增「為什麼我要付他？」帳務說明。
- 群主／副群主可手動指定部分付款路線與金額，剩餘由系統自動分配。
- 手動建議只允許淨應付者直接付給淨應收者，並限制超額分配。
- 記錄部分付款後，待確認金額不會再次被安排。
- 活動成員的待重新檢查名單不再與一般成員重複。
- 活動成員頁返回直接回活動。
- 底部導覽改為「支出 / 帳目 / 結算」，帳目不再使用人物圖示。
- 再次點目前底部頁籤會回到頂端；切換頁籤會保留各自捲動位置。
- 無支出活動顯示「尚未開始記帳」，不再誤顯示已結清。
- 支出修改紀錄不再顯示「第 X 版」。
- 通知與「我的」頁上方恢復與首頁一致的 Bopli Logo。
- 手機輸入 modal 依可視視窗避開虛擬鍵盤。

## 目前限制

目前資料仍主要儲存在瀏覽器 `localStorage`：

- 不是真正多人即時同步
- Google Authentication 尚未正式接上
- 邀請連結尚未接 Firebase / Firestore
- 不同裝置資料彼此獨立
- 清除瀏覽器網站資料會清除本機測試資料

## 核心帳務原則

- 付款人與分攤人獨立。
- 找零從實際墊付扣除。
- 平均、自訂金額、比例與數量分攤皆支援。
- 歷史付款紀錄不可因成員退出而消失。
- 待確認付款不視為完成，但會保留該筆付款額，避免再次安排。
- 建議結算只從淨應付者直接轉給淨應收者。
- 已開始還款的帳務維持保護，避免已處理的金額被任意改寫。
- 完整結算尾差只有群主／副群主能決定。
