# bopli_test.2.5｜朋友分帳管家

目前版本：**bopli_test.2.5**。部署網址：https://jia0796.github.io/bopli/

## 2.5 改版

- 群主／副群主建立結算快照後才能記錄新付款；帳務修改後需重新結算，既有付款仍可確認或處理爭議。
- 依付款當時帳務依據保護相關支出，無關支出可編輯，並檢查歷史還款是否仍有效。
- 個人、他人及全部結算表 PNG 分享，固定 1080 × 1350、多頁預覽與選取；不支援檔案分享時下載。
- 帳號／暱稱最多 14 顯示單位、支出最多 NT$1,000,000,000，超限立即提示。
- 草稿刪除需要確認；更新輸入提示文案。
- 依本次使用者要求，首次開啟 2.5 清除 2.4（含）以前的本機測試資料，保留 2.5 資料與其他網站資料。每個瀏覽器開啟新版時執行。

測試與優化報告：[REPORT_2.5.md](./REPORT_2.5.md)。測試重現方式：[TEST_GUIDE_2.5.md](./TEST_GUIDE_2.5.md)。

## 目前限制

目前資料仍主要儲存在瀏覽器 `localStorage`：

- 不是真正多人即時同步
- Google Authentication 尚未正式接上
- 邀請連結尚未接 Firebase / Firestore
- 不同裝置資料彼此獨立
- 清除瀏覽器網站資料會清除本機測試資料

## 核心帳務原則

- 付款人與分攤人獨立。
- 找零從實際墊付扣除。
- 平均、自訂金額、比例與數量分攤皆支援。
- 歷史付款紀錄不可因成員退出而消失。
- 待確認付款不視為完成，但會保留該筆付款額，避免再次安排。
- 建議結算只從淨應付者直接轉給淨應收者。
- 已開始還款的帳務維持保護，避免已處理的金額被任意改寫。
- 完整結算尾差只有群主／副群主能決定。
